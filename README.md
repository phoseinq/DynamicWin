# Halo

A smooth glass notch for Windows — a Dynamic Island for the desktop.

Built from scratch on **C# + WinUI 3 + Composition** so animation is synced to the
monitor refresh rate (120/144Hz), the glass is real acrylic (no banding, no low-res
look), and apps plug in as widgets. First-class Claude Code panel: usage bars, live
activity, and a Cancel that really stops the running prompt.

Status: **design / spec only. No code yet.**
