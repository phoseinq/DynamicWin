# Tech stack

- C# `LangVersion=latest`, `net9.0-windows10.0.19041.0`, `RuntimeIdentifier=win-x64`,
  `Nullable=enable`, `AllowUnsafeBlocks=true`. `RootNamespace=Halo` for `src/Halo.App`.
- Solution `Halo.sln` = 3 projects: `src/Halo.App` (WinExe, `Version` 3.x — bump on release),
  `src/Halo.Hooks` (console helper the agent hooks invoke), `tests/Halo.Tests` (xunit).
- **Only NuGet package: `System.Drawing.Common` 9.0.0.** Everything else — WinRT (SMTC,
  `UserNotificationListener`, Bluetooth), Core Audio, OLE drag/drop, shell icons, SQLite
  (`winsqlite3.dll` for `wpndatabase.db`) — is hand-written P/Invoke/COM in `Interop/Win32.cs`.
  Do not add packages without asking.
- Rendering: GDI+ (`System.Drawing`) → `UpdateLayeredWindow`. No WinUI, no XAML, no Skia, no D2D.
  (P2 pivot: `Windows.UI.Composition` was dropped — couldn't host bitmap content without
  `LoadedImageSurface`.) Fonts: Segoe UI + Segoe Fluent Icons / Segoe MDL2 Assets glyphs.
- Unpackaged app (no MSIX) — `UserNotificationListener` works unpackaged on this Windows build.
- Embedded resources: `Assets/claude.png`, `Assets/openai.png` (logical name `Halo.Assets.openai.png`).
- Installer: Inno Setup (`installer/Halo.iss`), icon generated by `installer/make_icon.py` (Python).
  Hook installers are PowerShell (`hooks/*.ps1`).
- Target OS is Windows 11 build 26200; several behaviours are build-specific (see `mem:notifications`).
